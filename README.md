# Job Hunt Agent Demo

A small demo project showing how an AI agent can help with a job search by automating the repetitive parts: finding openings, judging fit, and preparing application material.

## What this project is for

Job hunting involves a lot of repeated work. This demo explores how an agent can take on tasks such as:

- **Finding roles**: collecting job postings that match your target titles, locations, and keywords
- **Screening for fit**: comparing each posting against your skills and preferences and flagging the best matches
- **Preparing applications**: drafting tailored cover letters or resume talking points for a chosen role
- **Tracking progress**: keeping a simple list of roles, statuses, and follow-up dates

The goal is a clear, minimal example you can read, run, and extend, not a finished product.
